# Elasticsearch Indices – Data Storage Layer

Elasticsearch is used to store and query security events
generated by Auditd and Logstash.

## Indices

### 1. auth-logs
- Stores authentication-related events
- Fields include:
  - user.name
  - timestamp
  - source host

### 2. audit-logs
- Stores OS-level audit events
- Fields include:
  - user.name
  - uid
  - executed commands
  - accessed files
  - audit keys (usb_activity, home_access)

## Purpose
Elasticsearch enables:
- Fast search and filtering
- User-based activity analysis
- Insider threat investigation

This allows investigators to trace
"who did what, when, and where".
